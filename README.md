# chto-vzyat.ru uptime monitor

Независимая проверка сайта из GitHub Actions.

- Запуск каждые 5 минут, со смещением от начала часа.
- Три попытки с паузой перед созданием инцидента.
- Проверяются главная, публичный каталог и SEO-редиректы.
- При сбое создаётся одна открытая GitHub Issue, назначенная владельцу репозитория.
- После восстановления Issue получает время восстановления и закрывается.
- Полная диагностика каждой проверки остаётся в истории GitHub Actions.

Ручная проверка:

```bash
./check.sh
```

GitHub может задерживать scheduled workflows при высокой нагрузке. Этот монитор дополняет серверный таймер, но не заменяет специализированную SLA-платформу.

В публичном репозитории GitHub отключает scheduled workflows после 60 дней без активности. Раз в 1–2 месяца нужно проверить, что workflow остаётся active, или сделать небольшой осмысленный commit.
